# Banner assets

Four original title-frame assets generated for Cloud Disco and integrated with
HTML text overlays:

- `title-fire.png`
- `title-neon.png`
- `title-ice.png`
- `title-royal.png`
- `player-wings.png`
- `wings-fire.png`
- `wings-neon.png`
- `wings-ice.png`

The source renders were generated on a flat chroma-key background, converted to
alpha PNGs, and resized to 768 px wide. They are not extracted from another
game. Keeping text outside the images allows Vietnamese titles to remain sharp
and editable in `config/gifts.json`.

The four back-slot effects use separate artwork: fire, cyber neon, ice, and the
original purple royal wings.
