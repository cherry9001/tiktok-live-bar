📖 Hướng Dẫn Sử Dụng

4 bước để phát sóng TikTok LIVE với sàn nhảy 3D.

Bước 1

🖥️ Khởi động ÔNG CHÚ MMO Live

Mở file OngChuMMO_Live.exe. Chờ hiện NODE ONLINE ở góc màn hình game.

Bước 2

📱 Kết nối TikFinity

Mở TikFinity Desktop → đăng nhập → bật LIVE. Sang tab 🔴 Live → nhập username → Kết nối LIVE.

Bước 3

📺 Thêm vào OBS

Thêm source Game Capture → chọn cửa sổ ÔNG CHÚ MMO Live. Bấm F2 trong game để bật Chroma Key.

Bước 4

🎮 Test thử

Vào tab 🧪 Test Lab → bấm 30 người. Vào 🎯 Events để test gift thủ công.
